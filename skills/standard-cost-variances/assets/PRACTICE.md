# Standards, Variances & Control: guided practice

All example organizations, scenarios and numeric figures are synthetic and anonymous.

**Scenario — efficiency review (synthetic)**

Allowed material 4,400 kg at €8.20/kg for actual output; actual material 4,590 kg costing €39,474.

1. Determine the actual price per kg.
2. Compute material price and usage variances using cost variance = actual minus standard.
3. Reconcile actual to standard material cost.

**Facilitator check**: actual price €8.60; price variance `4,590×€0.40 = €1,836 U`; usage variance `190×€8.20 = €1,558 U`; combined `€3,394 U`; `€39,474 − €36,080 = €3,394`.

**Learning mode:** reveal facilitator checks only after the learner has attempted the question or asks for a complete answer.
