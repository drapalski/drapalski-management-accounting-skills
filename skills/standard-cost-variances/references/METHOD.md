# Standards, Variances & Control: method

All business illustrations and figures are synthetic.

**Sign convention**

Define all *cost* variances as `actual − allowed standard`: positive = unfavourable; negative = favourable. State sales conventions separately.

**Core formulas**

- `Material price variance = actual quantity × (actual price − standard price)`.
- `Material usage variance = standard price × (actual quantity − allowed standard quantity for actual output)`.
- `Labour rate variance = actual hours × (actual hourly rate − standard hourly rate)`.
- `Labour efficiency variance = standard hourly rate × (actual hours − allowed standard hours for actual output)`.

**Decision process**

1. Set actual output, then flex quantities to it.
2. Compute each component and confirm that components sum to the total input-cost difference.
3. Report F/U status and operational explanations separately.
4. Distinguish controllability and evidence from speculation.

**Worked synthetic example**

Allowed 2,700 kg at €6.40/kg; actual 2,810 kg at €6.70/kg. Price variance `2,810×0.30 = €843 U`. Usage variance `110×€6.40 = €704 U`; combined `€1,547 U`. Check: actual `€18,827` minus allowed `€17,280` equals €1,547.

**Common traps**: using budgeted output rather than actual output for allowed inputs; reversed signs; omitting a reconciliation.
