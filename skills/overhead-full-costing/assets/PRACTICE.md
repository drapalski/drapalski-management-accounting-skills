# Overhead Allocation & Full Costing: guided practice

All example organizations, scenarios and numeric figures are synthetic and anonymous.

**Scenario — engineering work orders (synthetic)**

Team A forecasts €315,000 overhead for 21,000 labour hours; Team B forecasts €204,000 for 8,500 machine hours. Work order X uses 16 labour hours in A and 7 machine hours in B.

1. Calculate departmental rates.
2. Assign overhead to X.
3. Explain when one blanket rate could misprice work orders.

**Facilitator check**: A `€15/labour hour`; B `€24/machine hour`; X overhead `16×€15 + 7×€24 = €408`. Rates apply to different drivers and should not be mechanically averaged.

**Learning mode:** reveal facilitator checks only after the learner has attempted the question or asks for a complete answer.
