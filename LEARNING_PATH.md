# Learning path

Choose an independent topic or progress through these capability groups:

| Foundation | Model the decision | Build control | Communicate impact |
|---|---|---|---|
| Cost concepts | Contribution & CVP | Budgets & forecasts | Performance measurement |
| Overhead allocation | Activity-based costing | Variances | Strategic cost management |
|  |  | Working capital | Decision simulator |

**Learning loop:** determine the purpose → name assumptions → choose formula → show workings → reconcile → interpret → test one changed assumption.

Start any topic with `study-coach` when you want guided questioning rather than the full answer.
