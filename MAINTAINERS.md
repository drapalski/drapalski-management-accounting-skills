# Maintaining the AI Skills Library

## Quality checklist

1. Keep each `SKILL.md` concise and decision-focused, with a name matching its folder.
2. Build scenarios from invented organizational settings and synthetic values.
3. Verify formulas, units, signs, reconciliations and interpretive statements.
4. Check that new materials are licensed or owned before distributing them.
5. Do not commit personal data, private client information or restricted documents.
6. Run `python scripts/validate_repo.py` before publication.
7. Test the Skills installer and a guided interaction in a supported AI agent.
8. Update linked documentation and images when adding new Skills.

## Publication

Upload the repository's extracted contents—not a ZIP—to the root of an empty GitHub repository. Set the default branch to `main`; no GitHub Pages deployment is required. Select any future reuse license only after deciding intellectual property terms.
